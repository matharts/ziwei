## 可读原文

下列转录直接来自第 75 幅原图。逗号、句号和换行由本次整理添加；没有用现代程序输出补字。`〔未辨〕` 明确表示不能可靠读出，不能视为完整校勘本。

### 安南北斗诸星诀

> 紫微天機逆行傍，隔一陽武天同當，又隔二位廉貞地，空三復見紫微郎。
>
> 天府太陰與貪狼，巨門天相及天梁，七殺空三破軍位，八星順數細推詳。

「傍」在维基文库录文写作「旁」，不影响方向。这里的「隔一」「隔二」「空三」均按中间空过的宫数解释，不把目的宫算作空宫。

### 安文昌文曲星诀

题下注「論本生時」。诗句可可靠读出：

> 子時戌上起文昌，逆到生時是貴鄉，文曲數從辰上起，〔未辨〕。

诗末句所在列存在墨块，本次不据维基文库补写。随后散文中可直接读出的操作片段为：

> 文昌星從戌上起子時……若丑時逆至酉宮安之。
>
> 文曲星從辰上起子時……若丑時順去巳宮安之。

省略号仅表示本笔记未作连续全文转录；两组起点与紧邻下一时辰的落宫均可读，足以核对昌曲的锚点和运行方向。

### 安左辅右弼星诀

题下注「論本生月」，诗句为：

> 左輔正月起於辰，順逢生月是貴〔未辨〕，右弼正月宮尋戌，逆至生月便調停。

「貴」之后字形本次不强定；不影响安置。末句直接可读为「逆至生月便調停」，与维基文库的「逆至正月便調停」不同。后续散文又写明左辅由辰起正月顺行，二月在巳；右弼正月在戌，二月在酉。由诗与相邻月份示例共同确定方向，不由现代实现反推。

## 从原文推导的有限结论

采用十二地支顺序 `子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥`，以下是对原文的算术表达，而非原文逐字记载：

| 范围 | 原图支持的安置 |
| --- | --- |
| 紫微组，以紫微所在宫为 0 | 紫微 0，天机逆 1，太阳逆 3，武曲逆 4，天同逆 5，廉贞逆 8 |
| 天府组，以天府所在宫为 0 | 天府 0，太阴顺 1，贪狼顺 2，巨门顺 3，天相顺 4，天梁顺 5，七杀顺 6，破军顺 10 |
| 左辅 | 辰起正月，按月顺行 |
| 右弼 | 戌起正月，按月逆行 |
| 文昌 | 戌起子时，按时逆行 |
| 文曲 | 辰起子时，按时顺行 |

紫微组：天机之后隔一空宫到太阳，故太阳为逆 3；天同之后隔二空宫到廉贞，故廉贞为逆 8；再空三宫返回紫微，与十二宫闭合相容。天府组：七杀为顺 6，空三宫再至破军，故破军为顺 10。

本次不重复核验五行局、生日安紫微的 150 格表，也不重复核验紫微到天府的十二宫映射；十四星的上述位移以各自起点已给定为前提。本次未核验四化原文，尤其不得据这份安星笔记改动壬干化科采用左辅的已确认项目取舍。

ziwei 当前架构

一个 Rust 领域内核：两条建盘入口共享统一计算路径，返回不可变本命盘；星曜索引查询、宫干四化与按需大限／流年均已实现。Node 与 Wasm 通过独立适配层调用同一核心。

图中是逻辑数据流：输入归一化与排盘计算都位于私有 rules.rs。Natal 保存本命事实及一次建立的私有位置索引；宫干四化、十二项期间宫职和十项年度摘要按需生成。连续飞化、历法换算、解释和断语不在当前范围。

唯一运行依赖是关闭默认特性的 ArrayVec，自有源码禁止 unsafe；其内部存储不属于公开 ABI。模块职责与所有权见包架构，性能测量与复跑方法见基准说明。
